# Changelog

All notable curation changes are recorded here.

## 2026-09-01

- Replaced the overlapping core/system/background categories with five mutually exclusive primary collections containing `41 + 41 + 6 + 3 + 4 = 95` records.
- Added orthogonal record-type, training-regime, state-source, teacher-topology, mechanism, supervision-signal, domain, artifact, and three-part evidence fields.
- Reorganized the main README as a 35-paper curated entry point with no repeated paper URLs; moved the complete corpus into five canonical catalogs.
- Added generated cross-cutting views by mechanism, topology, signal, domain, system report, artifact availability, and date.
- Upgraded the JSON schema, metadata validator, catalog renderer, contribution forms, and CI freshness checks for taxonomy v2.

## 2026-08-31

- Created the bilingual repository and explicit strict-MOPD inclusion rule.
- Added initial core MOPD, system/application, adjacent, offline MTKD, foundation, survey, and tutorial catalogs.
- Added machine-readable JSON metadata, duplicate/date/category/catalog-coverage validation, link-check CI, and contribution templates.
- Recorded primary-source search strategy and verification cutoff.
