The map separates training-state sources from teacher-combination mechanisms. Strict MOPD requires current or near-current student states, multiple independently identifiable teachers, and a direct distillation objective. The adjacent column describes boundary cases to inspect, not universal exclusions. Mechanism examples are intentionally non-exhaustive. No paper counts or dates are embedded.

To update the method map, open the `.drawio` source in diagrams.net, edit its text or shapes, and export the full page as SVG with its background and original page size. Keep labels as text and inspect the export for wrapping. To update the sharing image, edit its SVG source in a vector editor and export a 1280 × 640 PNG. Keep the repository address readable and inside the safe margins.

Both SVGs contain accessible titles/descriptions, editable text, and native vector shapes. Typography uses the Arial/Helvetica system-font stack; no external images, icon libraries, scripts, or web fonts are embedded. The assets follow the repository license.
