# Literature Refresh — 2026-10-05

This focused update adds 24 records to the September 8 snapshot: 16 multi-teacher on-policy, 5 offline multi-teacher, 2 adjacent or alternative, and 1 survey. The catalog now contains 134 records. Eighteen additions first appeared after the previous cutoff; six are backfills dated on or before September 8.

## Coverage and evidence

Searches combined multi-teacher/on-policy, multi-domain, expert routing, capability preservation, heterogeneous knowledge distillation, knowledge amalgamation, and September/October 2026 terms. Citation chaining and related public lists supplied leads; acceptance relied on primary papers, official metadata, and author-linked artifacts. Searches were run on 2026-10-05 (Asia/Shanghai).

For new entries, we read the primary metadata and relevant training/method sections to identify state provenance, distinct supervisors, and the student objective. This was a classification review, not full peer review, proof checking, reproduction, or a fresh reread of all 110 previous entries. The search is not an exhaustive systematic review. New preprints are not labeled peer reviewed merely because they appear here.

## Decisions requiring care

- **MAS-OPD:** multiple student agents use one frozen teacher under different role contexts. It is adjacent, not strict multi-teacher distillation.
- **ROSS:** the added relearning stage uses historical self-rollouts and masked offline supervision. Its upstream MOPD experiment does not make that stage on-policy.
- **ACLArena:** the MOPD analysis qualifies; the proposed mixture of LoRA experts is a separate approach. The arXiv metadata uses “Continue” while the manuscript uses “Continual”; the catalog retains the indexed title and records the discrepancy.
- **MAGA:** current-student response prefixes are sampled on fixed GUI inputs. This is not evidence of fresh full-environment trajectories.
- **SF-MOPD:** the EMA reference is auxiliary; separately trained visual specialists establish the multiple-teacher criterion.
- **Latent-MOPD:** the author repository says code is forthcoming. It is labeled a project page, not a verified implementation.
- **Med-RADIO:** feature-dispersion normalization is estimated offline, not learned dynamic teacher weighting.
- **Merge-of-Thought / IM-MOPD:** both contain actual student distillation, so a parameter-merging stage does not make them pure-merging exclusions.
- **Survey date:** [the publisher](https://www.annualreviews.org/content/journals/10.1146/annurev-statistics-043025-102547) gives September 17 as the first online date for A Statistical Perspective, before its September 27 arXiv submission.
